# Governance

OmaBlue is currently maintained by Jamie McCormick.

The maintainer retains final responsibility for scope, architecture, releases,
security policy, naming, and roadmap decisions. Contributions do not imply an
ongoing support commitment.

Additional maintainers may be invited after sustained, substantive, and trusted
contributions. The project may later move to a dedicated GitHub organization;
the protocol and repository structure should not depend on the current account.

If active maintenance ends, the repository will be archived or transferred to
a trusted maintainer rather than left with an apparently supported release.
