# OmaBlue Protocol v1

## Transport Independence

Protocol v1 uses one JSON object per frame. The first transport is NDJSON over a
restricted SSH command, but these models do not depend on SSH.

## Compatibility

- Every request includes `protocol_version` and a non-empty `request_id`.
- Servers reject unsupported versions, unknown request fields, and invalid
  limits.
- Clients ignore additive response fields within protocol version 1.
- Unknown event types are not silently treated as messages.
- A protocol-major change requires a new version number.

## Cursors

A cursor contains:

- `source_instance`: stable identity for one Mac-side source
- `database_generation`: identity for the current Messages database file
- `rowid`: exclusive physical scan position

Cursors are invalid if either identity differs from current status. The server
returns `resync_required`; it never silently starts at the current head.

## Requests

### Status

Returns current source identity and dynamically available capabilities.

### Sync

Returns a bounded batch of conversations and messages plus the authoritative
next cursor. `limit` ranges from 1 through 500. Clients persist the cursor only
after applying the complete batch.

### Watch

Streams events after a valid cursor. Events may be replayed. Clients deduplicate
by `event_id` and persist a cursor only after applying its event.

## Data Safety

- IDs are opaque strings.
- No Mac filesystem path crosses the protocol.
- Attachment filenames are display data, never local paths.
- Timestamps are RFC 3339 strings for display and filtering, never ordering.
- Source `rowid` and cursor order determine catch-up order.
- Missing text, receipts, avatars, and attachments remain explicit optional
  values rather than fabricated data.
- Unknown services, unavailable unread counts, absent attachment identifiers,
  and unknown reaction actors remain `null`.

## Mutations

Protocol v1 reserves mutations for a later milestone. Text send and attachment
send capabilities remain false until command idempotency and outcome-unknown
semantics are implemented and tested.
