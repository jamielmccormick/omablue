# Support

OmaBlue is experimental software built on undocumented macOS Messages storage.
It may break after macOS updates.

## Initial Support Matrix

- Current stable Omarchy release
- One physical Mac running a version supported by the pinned `imsg` release
- One logged-in macOS user and Messages account
- Regular OpenSSH over a private Tailnet
- Latest OmaBlue release only before 1.0

Other Linux desktops, public exposure, VMs, containers, SIP-disabled features,
and multi-user deployments are unsupported.

Use GitHub Discussions for setup questions and Issues for reproducible defects.
Never upload personal message data to either.
